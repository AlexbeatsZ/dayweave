# 时织 Dayweave 0.3.0

整合 Clearlist 与 Open Timelog，新增跨时区课程表和原生 Android / 小米桌面组件。

- 待办、番茄、活动计时、时间线、目标、课程共用同一份可验证数据与完整备份；旧程序 JSON 可显式合并迁移。
- 从任务详情开始正向计时，保存的时间记录保留任务关联。
- 日程时区与课程时区可独立设置。默认北京时间 `Asia/Shanghai`，支持 IANA 地区时区和固定 UTC 偏移。操作系统时区不变。
- CSV / JSON / ICS 课程导入、预览、合并；单双周、指定周、教室、教师和停课日期；当前/下一节课与双时区显示。
- Android 2×2 / 4×2 原生 RemoteViews 组件，独立进程、小米曝光刷新、系统重启和点击打开课程表。
- 统一 REST API、OpenAPI、CLI 与 Node 24 独立无界面服务，支持 ROG AI 决策系统调用 `/context`、管理任务、计时和课表。
- Windows x64 便携 EXE；Android APK；macOS arm64 / Intel DMG 与 ZIP。macOS ad-hoc 签名，未公证；Windows 未商业代码签名。

安装新程序后先在旧程序导出 JSON，再在时织设置中导入。两个旧程序、账号、数据库和安装目录均不自动迁移或替换。

新增 ROG 中心、局域网自动发现、单次邀请配对、加密载荷与离线三方合并；计时以开始/结束时间和暂停片段同步。手机和平板在应用打开时自动同步，系统冻结后台时下次打开补齐。Android 无 HTTP 服务；后台省电可能延迟组件课程边界刷新。小米商店小组件分发与审核、实体手机桌面/锁屏/重启、用户实体 Intel Mac、下载后的 Gatekeeper 和 ROG 现有决策系统对接均需分别验收，不由编译或模拟浏览器测试代替。

构建与运行证据见 [验证记录](../verification.md)。
