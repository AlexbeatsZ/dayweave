# 复旦课程网站导入

## 登录和读取

仅支持用户提供的[复旦教务系统个人课表入口](https://fdjwgl.fudan.edu.cn/student/sso/login?targetUrl=/student/for-std/course-table)。该入口会转到复旦统一身份认证，用户自行完成登录并选好学期，再点击“读取课表”。时织不代填账号密码，不读取登录表单，也不保存凭据到业务备份或同步文档。

Windows/macOS 使用隔离、无 Node/预加载桥的 WebContentsView，工具栏与远端页面分离；Android 使用不继承 BridgeActivity、不暴露 JavascriptInterface 的专用 WebView。只允许 HTTPS 官方教务、id、uis 主机导航，不下载文件或打开任意新窗口。Electron 导入会话是临时内存分区，关闭后清理；Android 仅销毁当前视图，不清理其他视图的全局 Cookie。

两平台使用 `src/fudan-capture.ts` 同一份提取脚本，构建时生成 Android asset。脚本仅在官方个人课表路径执行，读取当前选中的学期 ID 和学期起止，再通过同源认证 GET 读取该学期 `print-data`。返回值限于学期日期、课程名、星期、真实起止、教学周、教室、教师名称和稳定课程身份；不返回完整 HTML、学生身份、Cookie、Token 或教师联系信息。

## 预览与存储

`src/fudan-import.ts` 负责纯数据校验和转换。所有课程按 Asia/Shanghai 解释；实际 HH:mm 保留，教学周合并且稳定 ID 保证重复导入不产生副本。学校周日起算时，周日课程保留实际日期实例，避免被移到下一周。缺少学期日期、未知字段格式、不合法时间和空课表明确报错，不猜测学期和课程。

解析成功仍只生成既有 ImportPreview。用户确认后复用统一 `mergeSchedule`、store 和同步队列；跨学期或时区不一致时保留现有合并检查。取消登录返回 null，失败不改变任何已有课程。浏览器版不跨域读取登录课表，可使用文件导入；安装版提供原生网站入口。

## 验证边界

测试覆盖官方主机/路径限制、仅选中学期的读取、白名单投影、敏感信息不回传、捕获与解析契约、稳定 ID、周日起算和跨时区实际时刻。公开接口形状只作为事实研究，不复用第三方项目代码。真实账号、验证码/二次认证、校园网络限制和网站后续改版必须单独验收，自动化样本通过不等于真实登录成功。
