# 复旦课程网站导入

## 登录和读取

仅支持用户提供的[复旦教务系统个人课表入口](https://fdjwgl.fudan.edu.cn/student/sso/login?targetUrl=/student/for-std/course-table)。该入口会转到复旦统一身份认证，用户自行完成登录并选好学期，再点击“读取课表”。时织不代填账号密码，不读取登录表单，也不保存凭据到业务备份或同步文档。

Windows/macOS 使用隔离、无 Node/预加载桥的 WebContentsView，工具栏与远端页面分离；Android 使用不继承 BridgeActivity、不暴露 JavascriptInterface 的专用 WebView；首次打开登录入口前即使用桌面 User-Agent（保留本机 Chromium 版本）、宽页面与缩放适配，避免手机网页与桌面提取契约不一致。只允许 HTTPS 官方教务、id、uis 主机导航，不下载文件或打开任意新窗口。Electron 导入会话是临时内存分区，关闭后清理；Android 仅销毁当前视图，不清理其他视图的全局 Cookie。

两平台使用 `src/fudan-capture.ts` 同一份提取脚本，构建时生成 Android asset。脚本仅在官方个人课表路径执行，读取当前选中的学期 ID 和学期起止（兼容 window 属性与页面顶层词法变量），再通过同源认证 GET 读取该学期 `print-data`。页面或所选学期在读取中改变时，旧结果作废。错误仅返回白名单阶段码及 HTTP 状态，不转发学校响应正文。Electron 工具栏命令仅由本地工具栏发起，被主进程截获后禁止打开新窗口；学校视图不能调用此通道。返回值限于学期日期、课程名、星期、真实起止、教学周、教室、教师名称和稳定课程身份；不返回完整 HTML、学生身份、Cookie、Token 或教师联系信息。

2026-10-23 在用户已登录的 Chrome 个人课表核对：真实学期控件是 Selectize 背后的原生 `select#allSemesters`，搜索输入 `#allSemesters-selectized` 不包含选中的学期 ID。优先读取该原生 select，并保留旧版 `#semester` 兼容；读取结束时使用同一个选择规则校验学期没有变化。真实 `print-data` 返回 `studentTableVms[0].activities`，教师数组为 `teachers`，投影为已有 `teacherNames` 字段，不引入另一套解析路径。

学期列表只含日期时，优先采用同 ID 的 `currentSemester.weekStartOnSunday` 明确标记；否则依据学校提供的起始日是否为周日决定周锚点，以 UTC 日期计算，不受本机时区影响。本次真实学期起始日为 2026-09-06（周日），第一周的周一是 2026-09-07，不能提前到 8 月 31 日。测试样本必须覆盖这些真实控件和字段；桌面 UA、模拟 HTML 和构建通过不能替代登录后的页面契约核对。

## 预览与存储

`src/fudan-import.ts` 负责纯数据校验和转换。所有课程按 Asia/Shanghai 解释；实际 HH:mm 保留，教学周合并且稳定 ID 保证重复导入不产生副本。学校周日起算时，周日课程保留实际日期实例，避免被移到下一周。缺少学期日期、未知字段格式、不合法时间和空课表明确报错，不猜测学期和课程。

解析成功仍只生成既有 ImportPreview。用户确认后复用统一 `mergeSchedule`、store 和同步队列；跨学期或时区不一致时保留现有合并检查。取消登录返回 null，失败不改变任何已有课程。浏览器版不跨域读取登录课表，可使用文件导入；安装版提供原生网站入口。

## 手机自动更新

Android 用户确认网站导入后，在该设备本地保存所选学期、日期范围、网站课程/日期课程 ID 和最后检查时间，不保存账号、密码或另一份课表。浏览器会话仍留在系统 WebView 的私有会话存储中；不会进入业务备份、AI API 或跨设备同步。Electron 的临时登录分区不留存，因此本轮自动读取仅在 Android 提供。

应用打开、恢复前台或前台定时到期时，使用同一桌面 UA、同一采集脚本及现有会话，明确请求订阅学期，检查间隔 15 分钟。隐藏 WebView 不接管应用页面或焦点，无交互、无 JS 桥，完成、失败、超时和取消均销毁。后台没有定时任务；网站变化不会即时推送到已冻结的应用或组件。

自动更新只替换订阅拥有的课程和日期实例，包括撤课、改时间、改教室；手动新增课程、事件、节次、假日和显示天数保留。学校管理的行以网站为准。读回响应后以最新 store 状态合并，不使用请求发出时的课表快照。学期范围或时区不一致时停止应用结果，先在课表设置中统一，再通过网站导入确认。真实空课表只允许在已建立的订阅刷新中作为撤课处理，首次导入仍明确报空。

登录/显式导入和自动刷新互斥。打开导入、取消订阅、隐藏应用或销毁视图会取消在途读取并使旧回调失效；在确认预览前后都不能让旧刷新覆盖导入。自动刷新和确认导入共用 store 事务；写业务数据前将旧、新所有权 ID 的并集写入本地恢复记录，等待保存队列健康后才缩为新集合。即使乐观视图无变化，失败保存期间也不能丢掉旧集合，否则重启会产生清不掉的重复课程。

读取失败保留已有数据，在课表页显示具体阶段和“重新登录并读取课表”；生命周期取消不冒充学校故障。“课程操作 → 更多”提供立即更新和关闭自动更新，关闭只移除本机订阅，不删课程。其他已配对设备通过原有 ROG 通道接收更新后的业务课表，不共享学校登录会话或自动建立配对。

## 验证边界

本次已在真实登录的 Chrome 中只读核对 DOM 与官方 `print-data`：22 条授课行、9 个不同课程名称；最小白名单数据回放通过共用捕获脚本和纯转换器，复现旧版 `FUDAN_SEMESTER` 并验证修复后预览、教师与周锚点。没有向用户的业务存储导入课程；新安装包内点击读取及 Android WebView 的真实账户验收仍需分开报告。

领域测试、合成 Electron 原生窗口、Android JVM 生命周期与浏览器模拟 Capacitor 桥分别验证，不能相互替代。刷新回归包括失败写盘、无变化重试、显式导入中的迟到响应和快速前后台切换。测试覆盖官方主机/路径限制、仅选中学期的读取、白名单投影、敏感信息不回传、捕获与解析契约、稳定 ID、周日起算和跨时区实际时刻。公开接口形状只作为事实研究，不复用第三方项目代码。真实账号、验证码/二次认证、校园网络限制和网站后续改版必须单独验收，自动化样本通过不等于真实登录成功。
