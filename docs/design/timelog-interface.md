# 记录界面

## 范围与视觉

记录模块包含时间线、计时、目标。手机由时织底栏的记录进入，顶部三子页支持点击与左右滑动；记录统计集中在统计页。手机与桌面共用相同的子页和领域计算。设置、备份和 AI API 属于主程序工具，不再形成第二个独立应用。

界面共用中性灰阶与冰蓝强调色，背景、卡片、按钮、文字和浅暗主题由全局语义变量定义。活动及活动标签可自定义颜色，只用于分类标记与图表，不大面积填充普通背景。正文使用本机系统字体；计时数字用 Bahnschrift / SFMono / Consolas，不请求外部字体。布局细节见 mobile-interface.md。

## 时间线

- 最新结束时间在上，较早时间在下；今天只显示已过去时间，历史日显示完整一天。每个有效片段独立成卡，跨日片段按所选日程时区截断，保留暂停空隙。
- 空闲从已保存的有效片段和所有未结束计时的预留区间推导。暂停时仍保留从计时开始到现在的时间，但不增加累计时长；结束后释放暂停空档。点击空闲预填完整起止，可缩短后补记；不提供不足一分钟空闲的显示选项。
- 记录可编辑、删除或在存在空闲时向上/下填满。上方延长结束，下方提前开始，只到相邻区间或日界线；先展示影响范围，再于最新事务复核记录版本与空闲。片段相接时合并，保留原性质。
- 手机日期导航复用日计划的周日期条，仅在时间线用于历史跳转。接近底部自动追加前一天，短列表继续加载到可滚动，没有手动加载按钮或七天上限。
- 跳转某天重设浏览窗口，普通滚动只更新当前可见日。顶部只显示日期，不放每日摘要；记录时间放统计页，不展示积极时间。每个编辑/补空档操作携带自己的日期，不使用顶部锚点代替。
- 记录侧栏可按活动、活动标签筛选；顶部不放搜索与主题按钮。
- 自动/对照模式复用记录卡片风格，按记录边界自动展开短片段、压缩长空档，不提供手动缩放；各设备共用自动记录区域，与手动列共享同一时间映射。手机不允许页面或时间线内部左右滚动，重叠卡片按可用宽度并排缩窄，文字省略后点击查看原有详情。布局与来源身份边界见 automatic-records.md。

记录编辑共用底部面板：时长预览、活动、起止时间、描述、标签和固定保存。未修改的毫秒和历史性质保持原样；并发变更不能被旧表单覆盖。记录与计时起止编辑遇到占用冲突时在面板内说明冲突时间，草稿可继续修正。

## 计时

未运行时只显示按性质分组的活动图标和名称；积极、日常（中性）、消极三组末尾各有一个“＋”新建卡片，空组也保留。新建复用同一个活动 Editor，默认性质来自所点分组，仍可手动更改；编辑已有活动则保留该活动的性质。不显示正计时、预设、起止调整或独立管理活动按钮。

点按活动直接开始正计时。可排序的活动（组内不止一个）按住 350 ms 抬起，随即拖动即可在同性质组内调整顺序，顺序保存在活动的 `order` 并参与同步；仍静止到 650 ms 时取消拖动并立即打开 Editor，不等松手。组内只有一个活动时触屏静止 450 ms 即打开 Editor。移动超过 9 CSS px 或触摸取消会取消尚未触发的长按，不开始计时。弹窗打开后消费本次手势的松手、兼容点击和触摸结束传播，不能误关弹窗、触发其中的控件、启动计时或切换子页；下一次真实触摸仍可正常编辑/关闭。鼠标不启用长按，精细指针环境直接显示独立铅笔按钮；右键、键盘 F2/Shift+F10 继续打开同一个 Editor，Tab 可到达铅笔按钮。手机触屏不显示这排鼠标按钮。

开始计时后才显示控制：活动标题与状态、时间圆环、圆环内暂停/继续，下面是正计时与倒计时预设、两列起止摘要。5、30、45、60 分钟为默认预设，后面的加号管理新增/删除，配置持久化并参与同步。选择未来结束时间进入倒计时；过去的完整起止范围保存为已结束记录，不显示成负倒计时。

运行页使用聚焦时间卡片与关联内容卡片：手机纵向排列，宽屏并列；普通背景灰阶，活动色只做图标，冰蓝突出时间与主要操作。关联卡片集中放相关标签、相关计划和活动图标加描述；下一个活动、完成、取消放同一操作行。开始、取消与下一活动切换时回到面板顶部，避免沿用活动选择页的滚动位置。相关计划从今天日计划中选择，已绑定但之后被移到别日的任务仍须能辨识。任务行启动时继承所属清单的活动映射并绑定该任务，不复制一套任务计时器。

起止摘要下方直接显示“接上条记录 HH:mm”，一次点击把开始时间改为上一条记录的结束（用户 2026-11-04 要求，这是最常用的修正，不能只藏在调整面板里）；开始已对齐时隐藏。起止摘要打开统一调整面板，开始时间快捷项为“接上条记录”“5/15/30 分钟前”“现在”，结束时间快捷项为“不设结束（正计时）”。调整保留暂停间隔并检查时间范围。所有时间选择按日程时区解释。

相关标签直接在运行页用标签块点选，末尾“新标签＋”输入新标签，改动立即保存到计时，不再弹出逗号输入框。记录编辑器、计时页与目标规则共用 `TagChips` 的标签块与新增输入，快捷时间统一为 `quick-chips` 块，不再混用按钮、文字链接和逗号文本框。

完成把当前描述、标签、任务关联和有效片段保存到同一个记录 ID。下一个活动先选择活动，然后以同一事务边界完成当前项并开始下一项。取消放弃当前未保存计时。暂停不计时，继续顺延倒计时截止；到期按计划截止保存，迟到唤醒不额外计入时间。番茄钟、休息周期及相应设置均移除。

离开计时页保留运行栏，可暂停/继续或返回。关闭应用后的显示由持久时间戳恢复，不靠逐秒计数。ROG 可在后台执行到期收尾；Android 在前台/恢复时按截止补齐，不承诺系统冻结 WebView 时即时写入或同步。

## 目标与统计

目标按用户分组显示双列紧凑卡片，显示组内上期达标数、统一图标、规则摘要、剩余时长、带阶段刻度的进度条与状态。图标按类型统一（用户 2026-11-04）：“至少”计时目标为主题蓝秒表，“不超过”为红色秒表（卡片边框与进度同色），绑定待办为清单图标，手动目标在图标位置直接放可点的勾选圈（绝对定位，不能嵌进编辑按钮）。不再显示活动图标。卡片可长按拖动在组内排序（复用 `useSortDrag`，顺序存 `order`）。点击编辑，菜单直接删除。目标页按实际当前日与自然周计算，不显示日期切换，也不放历史热力图。

完成热力图放在 统计 › 记录 › 目标（用户 2026-11-04 要求），随统计日期浏览历史：每日目标 8 个自然周（周一起，每行一周），每周目标 14 周。颜色在灰色与主题蓝之间按完成比例线性混合：有阶段的计时目标按“达到的阶段数 / (阶段数+1)”均分；无阶段的“至少”目标按进度比例；“不超过”无阶段时达成即全蓝；待办目标按完成比例；手动目标 0 或 1。早于第一条保存记录的周期显示为空格（无数据），避免“不超过”目标在开始记录前全部显示为达成。

行为规则沿用同样的双列目标卡。自定义标题下显示两行灰色小字「触发条件：…」「目标行为：…」，进度条的位置使用一个下拉框。选项依次为「未选择」「未触发」「已触发，未全部执行」「已触发，全部执行」。选项变化立即保存，选回「未选择」清空当天回顾。统计页点日期查看原答案，所有已选择的答案使用相同的颜色。

手机统计包含每日、待办、记录三个子页。每日合并当天任务与记录概况，日期控件可快速移动，并可进入相应时间线；记录页统计全部已保存记录。总时长取区间并集，活动分布按记录累计；历史性质使用记录保存的值。桌面分析的当日/7 天/30 天趋势与点击回到某日可继续使用同一计算，不另存统计副本。

## 操作与恢复

侧栏、编辑和确认共用 `Modal` 管理焦点与最顶层 Android 返回；导入先预览并导出本机安全备份。界面错误说明原因，业务校验失败保留草稿，持久化失败不能伪装成功或静默清空数据。布局不横向溢出，固定操作适应软键盘、安全区与减少动态效果。

原版研究见 docs/research/uptimer.md。截图和静态交互线索不能证明复刻了原版完整分支；构建、浏览器检查、安装与实体设备体验需分别记录。

判定方式“自动化脚本”（用户 2026-11-04）：目标编辑器列出同步的脚本库（单选卡片，显示脚本说明或错误），下方按脚本 `params` 声明生成参数表单；“新建脚本”从模板开始，“导入脚本”读取 .js，“编辑脚本”打开带代码框、试运行（今天、当前参数，显示结果与 ctx.log）、导出和删除（被目标使用时拒绝）的编辑器。脚本目标卡片用主题蓝代码文件图标，状态行显示脚本的 note（出错时显示错误），右侧显示脚本名。设计与限制见 goal-scripts.md。
