# 记录界面

## 范围与视觉

记录模块包含时间线、计时、目标。手机由时织底栏的记录进入，顶部三子页支持点击与左右滑动；记录统计集中在统计页。桌面可保留时间模块内部的分析入口，共用相同领域计算。设置、备份和 AI API 属于主程序工具，不再形成第二个独立应用。

界面共用中性灰阶与冰蓝强调色，背景、卡片、按钮、文字和浅暗主题由全局语义变量定义。活动及活动标签可自定义颜色，只用于分类标记与图表，不大面积填充普通背景。正文使用本机系统字体；计时数字用 Bahnschrift / SFMono / Consolas，不请求外部字体。布局细节见 mobile-interface.md。

## 时间线

- 最新结束时间在上，较早时间在下；今天只显示已过去时间，历史日显示完整一天。每个有效片段独立成卡，跨日片段按所选日程时区截断，保留暂停空隙。
- 空闲是全部记录和进行中计时有效区间并集的补集，不把重叠记录误当空白。点击空闲预填完整起止，可缩短后补记；不足一分钟空档可隐藏，隐藏不修改数据。
- 记录可编辑、删除或在存在空闲时向上/下填满。上方延长结束，下方提前开始，只到相邻区间或日界线；先展示影响范围，再于最新事务复核记录版本与空闲。片段相接时合并，保留原性质与积分速率。
- 手机日期导航复用日计划的周日期条，仅在时间线用于历史跳转。接近底部自动追加前一天，短列表继续加载到可滚动，没有手动加载按钮或七天上限。
- 跳转某天重设浏览窗口，普通滚动只更新当前可见日。顶部日期、记录时长、积极时长与积分始终按可见日计算；每个编辑/补空档操作携带自己的日期，不使用顶部锚点代替。
- 记录侧栏可按活动、活动标签筛选；已有搜索能力可继续服务桌面等入口，手机顶部不额外占据搜索栏。

记录编辑共用底部面板：时长预览、活动、起止时间、描述、标签和固定保存。未修改的毫秒、历史性质和积分速率保持原样；并发变更不能被旧表单覆盖。

## 计时

选择活动开始普通正计时；可预先选择结束时间，未来截止则进入倒计时。5、30、45、60 分钟为默认预设，后面的加号管理新增/删除，配置持久化并参与同步。过去的完整起止范围保存为已结束记录，不显示成负倒计时。

运行页包含活动名称、时间圆环、累计或剩余时间、积分、起止摘要、暂停/继续、完成、相关标签、活动内容和相关计划。相关计划从今天日计划中选择，已绑定但之后被移到别日的任务仍须能辨识。任务行启动时继承所属清单的活动映射并绑定该任务，不复制一套任务计时器。

起止摘要打开统一调整面板，允许修改开始时间、选择或清除结束时间。“当前时间”和“上一条记录末尾”作为开始时间快捷项，只放在该面板中。调整保留暂停间隔并检查时间范围。所有时间选择按日程时区解释。

完成把当前描述、标签、任务关联和有效片段保存到同一个记录 ID。下一个活动先选择活动，然后以同一事务边界完成当前项并开始下一项。取消放弃当前未保存计时。暂停不计时，继续顺延倒计时截止；到期按计划截止保存，迟到唤醒不额外计入时间。番茄钟、休息周期及相应设置均移除。

离开计时页保留运行栏，可暂停/继续或返回。关闭应用后的显示由持久时间戳恢复，不靠逐秒计数。ROG 可在后台执行到期收尾；Android 在前台/恢复时按截止补齐，不承诺系统冻结 WebView 时即时写入或同步。

## 目标与统计

目标按每日、每周分组，使用 UpTimer 参考图中的双列紧凑卡片，显示组内达标数、活动图标、剩余时长、百分比与状态。点击编辑，菜单直接删除，历史记录保留。目标按实际当前日与自然周计算，不显示日期切换，不新增截图中的结算、商店或奖励逻辑。

手机统计包含每日、待办、记录三个子页。每日合并当天任务与记录概况，日期控件可快速移动，并可进入相应时间线；记录页统计全部已保存记录。总时长取区间并集，活动分布与积分按记录累计；历史性质和速率使用记录保存的值。桌面分析的当日/7 天/30 天趋势与点击回到某日可继续使用同一计算，不另存统计副本。

## 操作与恢复

侧栏、编辑和确认共用 `Modal` 管理焦点与最顶层 Android 返回；导入先预览并导出本机安全备份。界面错误说明原因，业务校验失败保留草稿，持久化失败不能伪装成功或静默清空数据。布局不横向溢出，固定操作适应软键盘、安全区与减少动态效果。

原版研究见 docs/research/uptimer.md。截图和静态交互线索不能证明复刻了原版完整分支；构建、浏览器检查、安装与实体设备体验需分别记录。
