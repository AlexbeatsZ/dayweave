# 时迹界面

## 范围与布局

桌面主导航只有时间线、计时、目标、分析四项。首屏为时间线；设置、数据备份和
AI API 为工具弹窗，活动管理放在计时面板。暂不提供商店和奖励兑换入口。
历史备份中的奖励字段保留，保证旧数据可读，但新界面不使用这些功能。

记录模块共用时织主界面的中性灰阶与冰蓝强调色，使用全局语义变量；背景、卡片、按钮、文字、边框及浅暗色切换均由同一主题定义。暗色正文为白/浅灰，大面积容器不使用蓝底。活动颜色仅作分类色标，积极与消极颜色仅作状态反馈。
字体为本机 Segoe UI / Microsoft YaHei / 系统回退，计时数字使用 Bahnschrift /
SFMono / Consolas；不请求外部字体。视觉重点是倒序的卡片时间线与左侧时间边界。

## 时间线

- 最新结束时间在上，较早时间在下；当日只显示已过去的时间，历史日显示完整一天。
- 每个有效片段独立显示卡片，保留暂停空隙；跨日记录按当前日期截断显示。
- 空闲由全部记录和进行中计时的有效区间并集取补集计算，不能把重叠记录间误认为空白。
- 空闲也显示为卡片；点击预填该空闲的完整起止时间，可缩短为 15/30/60 分钟后补记。
- 每条记录提供编辑、软删除，以及存在对应空白时的向上/向下填满按钮。
  上方延长结束时间，下方提前开始时间；仅延伸到相邻区间或日界线，不能跨过其他记录。
  操作先显示影响时段，再在最新事务中重新校验记录版本和空闲范围。
- 填满暂停间隙后，如果同一记录片段相接，合并为连续片段。保持原活动积分速率。
- 不足一分钟的空白默认隐藏，可通过选项显示；隐藏只影响显示，不改变原数据。
- 显示当日记录时长、积极时长和积分，支持日期切换和活动/描述/标签搜索。

## 计时、目标与分析

选择活动立即开始并进入独立计时页。可描述、暂停、继续、专注或放弃。
结束按钮在同一保存事务中读取描述，保存记录后回到今天的时间线。
暂停片段不计时；关闭后根据时间戳恢复。可选从最近已结束记录的结尾开始。

目标为每日/每周活动时长，显示进度、剩余时长与达标状态。分析可切换当日、7 天、
30 天，展示时长趋势、活动统计、积分和记录数；点击趋势柱回到对应日期。
累计积分仅供反馈统计，不提供商店。

## 操作与适配

手机共用时织的待办、记录、课表、更多四项底部导航；时间线/计时/目标并入记录顶部三子页，支持点击与左右滑动。时间线自动追加历史，当前可见日期与积分同步；日期控件快速跳转。记录与桌面共用条目渲染和底部编辑面板，目标采用每日/每周分组的双列紧凑卡片，分析保留圆环和五分钟时间分布；详细规则见 mobile-interface.md，状态归属见 architecture.md。布局避免横向溢出，表单提供明确标签与键盘焦点；尊重减少动态效果。
暗色支持跟随系统/浅色/暗色，偏好保存在设备；不改变业务备份格式。
删除、填满、放弃计时先确认；导入先预览和导出本机安全备份，失败保留原数据。
所有 UI 错误说明具体原因；读库失败提供恢复导出，不能静默清空。

原版依据和未实现项见 docs/research/uptimer.md；静态字符串可证明交互线索存在，
不能声称还原了原版完整布局、全部分支或源代码。
