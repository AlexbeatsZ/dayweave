# 手机界面与交互

## 适配范围与参考

视口宽度不超过 700 CSS px 时由 `src/phone/MobileApp.tsx` 提供独立手机布局；更宽的平板和桌面保留桌面布局。两种布局共享 store、数据模型、持久化、同步和主题，不创建第二份任务或计时数据。

空间安排参考用户提供的 Sefirah 文件夹中 12 张 Todo/UpTimer 截图：周日期条、底部新建面板、时间边界与记录卡片、分组活动、分析圆环/时间分布、双列目标。只参考布局与操作线索，不复制截图资产、品牌色或原程序代码。颜色使用全局语义变量；活动颜色仅用作分类标记。

## 灰阶与强调色

用户要求普通背景用灰色、正文用白色，强调色只选一种蓝色或蓝绿色。当前选择冰蓝色，暗色页面的主要比例为中性灰底和白字，蓝色只用于主按钮、选中日期/导航、运行状态与少量交互提示。

| 用途           | 暗色值            |
| -------------- | ----------------- |
| 页面底色       | #181818           |
| 普通卡片/面板  | #252525           |
| 输入与次层容器 | #202020           |
| 分隔线         | #3c3c3e           |
| 正文/次级文字  | #f4f4f5 / #adadb2 |
| 强调色         | #76b9ed           |

普通日期、统计数字、时长预览和跨页运行栏使用灰阶，不铺大块蓝底。活动色保留在色标、分布图和小图标；积极/消极仍有语义状态色。浅色模式保留供用户切换，采用中性浅灰与深灰文字以保证可读性，不强改已保存的外观偏好。网页预加载、Electron 背景、Android WebView/启动屏和原生组件同步使用同一灰阶。

## 导航与待办

- 顶部保留页面标题、日程时区、任务搜索和主题切换。全局底栏固定为待办、记录、计时、课表、更多；记录模块在手机上不再嵌套第二条导航。
- 更多底部面板提供分析、目标、日历、最近七天、四象限、番茄专注、完成/回收站、统计、设置与同步、清单与标签。四象限继续使用共用的紧急/重要计算。
- 待办用周日期条切换日期，支持前后周、任意日期和回到今天。今天包含逾期任务，选其他日期只展示该日任务；日期判断使用日程时区。
- 新建任务由右下角加号打开底部面板。清单、标题、描述、日期、子任务、优先级、重复在同一面板提交；标题中的 #标签按共用格式写入。未保存的草稿只存在面板内，取消会丢弃；保存成功后才关闭。保存失败保留输入并显示原因。
- 任务详情全屏展示。任务行可直接开始关联活动计时。软删除提供撤销，原来的重复任务与回收站语义保持一致。

## 时间记录与计时

- 记录按结束时间倒序排列，左边显示每段的起止时间，右边是时长、积分、描述与标签。一个暂停/继续记录仍是一个 ID，但每个有效片段独立显示卡片。空档直接点击补记。
- 可以连续加载更早一天，最多七个日期组；编辑、删除和填满空档必须使用所选日期组重新校验范围，不能误用当前顶部日期。
- 记录编辑使用底部面板：时长预览、活动标签、起止日期/时间、描述、标签和固定保存操作。日期显示分成两行，点击使用原生日期时间选择器。未修改的毫秒、历史性质和积分速率原样保留。
- 活动按积极、日常、消极分组，点击即开始计时。暂停、继续、结束共用已有时间戳与片段模型；不足一秒时不能结束保存，避免生成无效记录。
- 离开计时页后显示底部运行栏，可以查看累计有效时长、暂停/继续或回到计时页。显示值由开始时间和片段计算，不能持久化逐秒计数。ROG 同步和 AI API 继续写入同一 store。
- 分析包含日/7天/30天、活动圆环、历史性质占比、五分钟时间格、趋势与可展开活动记录。总时长合并重叠区间，活动占比按记录累计；性质与积分使用记录保存的值，不随活动分类修改而追溯变化。所有日期使用设置中的日程时区。

## 返回、尺寸和持久化

底部面板使用原生 modal dialog 和焦点约束。Android 返回先由最顶层弹窗捕获，只关闭这一层；再关闭任务详情/搜索，最后回到待办或交由原生退到后台。对话框卸载后恢复原焦点。

手机采用动态视口、安全区域、内部滚动和底部固定操作；软键盘缩短视口时面板可滚动，保存按钮仍可触达。输入至少 16 px，主要按钮至少 44 px，支持减少动态效果。

业务校验拒绝只返回当前操作错误，不把全局 store 标记为磁盘故障；实际持久化失败继续阻止伪保存并提供备份/恢复。课程、Android 组件、日程时区和前台/恢复同步边界见 integration.md、platforms.md、sync.md。

## 验证入口

`tests/e2e/phone.spec.ts` 使用独立浏览器存储和 UTC-4 设备时区验证：周日程与底部任务面板、重载后任务/子任务、历史记录保真、原生返回层次、同 ID 暂停/继续与跨页面运行栏、统计与历史性质、业务拒绝后的继续保存、缩短视口、浅暗系统主题及 360/390 px 与桌面断点。浏览器模拟不能代替实体手机键盘、系统手势或组件验收。
